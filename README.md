# Pokédex Web Application

A simple **Pokédex web application** built using **HTML, CSS, and JavaScript**.
This project fetches Pokémon data from a public API and displays information about all Pokémon dynamically on the webpage.

## Features

* Fetches Pokémon data using a public API
* Displays Pokémon **name, image, type, and other details**
* Dynamically loads Pokémon using **JavaScript**
* **Responsive design** that works on different screen sizes
* Clean and simple Pokédex interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Pokémon API (PokéAPI)

## How It Works

When the webpage loads, JavaScript sends requests to the API and retrieves Pokémon data.
The application then dynamically creates Pokémon cards and displays them on the page using DOM manipulation.
